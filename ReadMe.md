To run the programm:

1. Create an environment:
    - open the console
    - uv venv .venv --python 3.14
2. Install the dependencies:
    - uv pip install --python .venv\Scripts\python.exe -r requirements.txt
3. Activate the environment:
    - .venv\Scripts\Activate.ps1
